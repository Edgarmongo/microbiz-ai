# MicroBiz AI

**面向小微企业的本地优先 AI 经营管理平台**

MicroBiz AI 是一个面向小微企业和个体经营者的开源项目，旨在帮助用户整理经营数据、分析现金流、理解经营状况，并逐步利用本地 AI 能力辅助日常经营决策。

项目采用 **Local-first（本地优先）** 的设计理念，优先让企业数据保存在用户自己的电脑上。通过传统业务逻辑与本地 AI 能力相结合，在保障数据可控性的同时，探索 AI 在小微企业经营管理中的实际应用。

> 项目目前处于早期开发阶段，功能与技术架构将随着开发和验证持续演进。

## 项目愿景

小微企业和个体经营者往往缺少专业的数据分析工具，也很难承担复杂经营管理系统的实施和维护成本。

MicroBiz AI 希望降低经营数据分析的门槛，让用户能够更方便地管理业务数据、了解现金流状况，并将分散的数据转化为清晰、可理解的经营信息。

项目长期关注以下方向：

- **经营数据管理：** 整理和管理企业日常经营数据。
- **现金流分析：** 帮助用户理解资金流入、流出和现金流趋势。
- **AI 辅助分析：** 利用本地 AI 模型进行信息提取、分类建议和经营报告草稿生成。
- **经营报告：** 将真实业务数据整理为可追溯、可复核的经营分析报告。
- **数据自主权：** 尽可能让用户掌控自己的数据、模型选择和运行环境。

## 核心设计理念

### 1. Local-first：本地优先

企业经营数据具有较高的敏感性。MicroBiz AI 优先采用本地运行方案，让业务数据保存在用户自己的电脑上，并逐步完善本地数据管理、备份和导出能力。

### 2. 业务规则与 AI 分工

AI 不应替代确定性的业务计算。

- Java 业务逻辑负责金额计算、数据校验、业务规则和数据一致性。
- 本地 AI 模型负责辅助信息提取、内容分类、自然语言解释和报告草稿生成。
- 重要分析结果应能够追溯到原始数据，并允许用户检查和修正。

### 3. 可追溯的数据与报告

经营分析需要明确的数据依据。项目计划逐步建立数据校验、处理记录和报告版本管理机制，避免数据修正后历史报告失去原有依据。

### 4. 开源与可扩展

项目采用模块化设计，逐步扩展数据导入、经营分析、核算、报告生成和 AI 能力，尽量保持清晰的模块边界，方便开发、测试和社区协作。

## 计划中的功能

以下是项目规划，不代表所有功能已经实现。

| 功能模块 | 规划内容 |
|---|---|
| 数据导入 | 从 CSV 等常见格式导入业务数据 |
| 现金流分析 | 统计资金流入、流出及现金流趋势 |
| 经营分析 | 基于真实业务数据生成经营指标 |
| 本地 AI | 辅助数据提取、分类和内容生成 |

## 技术架构

项目采用前后端分离、模块化单体架构。

### 前端

- Vue 3
- TypeScript
- Vite
- Element Plus
- Axios

### 后端

- Java 21
- Spring Boot 4.x（以实际依赖兼容性验证结果为准）
- Maven 多模块工程
- REST API

### 数据与 AI

- MySQL：业务数据持久化
- 本地 AI 推理服务：为 AI 辅助能力提供模型支持
- 数据库迁移脚本：管理数据库结构的演进

### 工程结构

```text
microbiz-ai/
├── docs/                       # 架构、需求与技术决策文档
├── frontend/                   # Vue 前端
├── backend/
│   ├── microbiz-boot/          # 应用启动入口与 API
│   ├── microbiz-common/        # 公共组件
│   ├── microbiz-import/        # 数据导入模块（规划中）
│   ├── microbiz-ai/            # AI 能力模块（规划中）
│   ├── microbiz-business/      # 经营分析模块（规划中）
│   ├── microbiz-accounting/    # 核算模块（规划中）
│   ├── microbiz-report/        # 报告模块（规划中）

│   └── migrations/             # 数据库迁移脚本
```

## 本地开发

### 1. 获取代码

```bash
git clone https://github.com/<你的 GitHub 用户名>/microbiz-ai.git
cd microbiz-ai
```

### 2. 启动后端

```bash
cd backend
./mvnw spring-boot:run -pl microbiz-boot
```

Windows PowerShell 可执行：

```powershell
cd backend
.\mvnw.cmd spring-boot:run -pl microbiz-boot
```

### 3. 启动前端

打开另一个终端：

```bash
cd frontend
npm install
npm run dev
```

开发环境默认使用 Vite 提供前端页面，并通过代理访问后端 API。具体启动条件以当前代码和配置为准。

> 注意：以上为预期开发流程。随着工程初始化、数据库配置和功能开发，实际命令及运行要求可能调整。

## 数据与使用边界

MicroBiz AI 的目标是辅助经营数据整理与分析，而不是替代专业会计、税务、审计或法律服务。

分析结果取决于用户提供的数据质量。涉及财务、税务、融资等重要事项时，用户应核对原始凭证及适用规则，并根据需要咨询专业人员。
